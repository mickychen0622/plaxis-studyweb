Chapter 3 · 分類 ① · 2 張表

計算結果

每算完一步，PLAXIS 就把那一步的結果寫進這兩張表。Result 存「每一塊網格」的位移、應力、孔隙水壓；GlobalResult 存「整個模型」的收斂資訊，例如 ΣMstage、疊代次數。檔案 3 GB 幾乎都在這裡。

這一類要回答

L10 開挖結束時，洞室周圍的位移和應力是多少？要從哪裡讀、怎麼解碼？

這一類的表

Result5,687,299 筆GlobalResult164,985 筆

Python 範例都接在 共用開頭 之後執行；下方「執行結果」是實際跑出來的輸出。

1.1

Result

每一步、每一塊網格的計算結果：位移、應力、孔隙水壓…

筆數 5,687,299欄位 9

PLAXIS 每算完一步就往這張表寫入一批列。每一列 = 「哪一步 × 網格的哪一塊 × 哪一種量 × 排在哪裡」的一包數字。全部 5,687,299 列、約 3 GB，是整個檔案的主體。

欄位型別意思
IDPKINTEGER流水號
ComponentSizeINTEGER NOT NULL每個點有幾個分量。位移 2（ux, uy）、有效應力 4（σxx, σyy, σzz, σxy）、純量 1
CreatorIDFKINTEGER NOT NULL由哪個程式寫入，幾乎都是 2 = Kernel（計算核心） → Creator
MeshEntityIDFKINTEGER NOT NULL這包數字屬於網格的哪一塊 → MeshEntity
K_StepsIDFKINTEGER NOT NULL哪一個計算步；再經 K_Steps 對到施工階段 → K_Steps
VariablesIDFKINTEGER NOT NULL哪一種量（位移、應力…） → Variables
DataLayoutIDFKINTEGER NOT NULL數字排在哪裡：節點、積分點，或整塊一個值 → DataLayout
DataInterpretationIDFKINTEGER NOT NULL數字格式：Double、Float、SignedInt32… → DataInterpretation
DataBLOBBLOB NOT NULL真正的數值，二進位。長度 = 筆數 × ComponentSize × 每個數字的 bytes

一筆結果由四個編號決定

先看某一步、某一塊網格存了哪些量。下面的 40 是 L01 的最後一步（見 K_Steps），336 是緊鄰主廠房頂拱的一個岩體區塊（見 MeshEntity）。

SQL（sqlite3 終端機或 Python 皆可）
SELECT v.Name AS 變數, dl.Description AS 排列位置, r.ComponentSize AS 分量數,
       di.Description AS 格式, length(r.Data) AS bytes
FROM Result r
JOIN Variables v           ON v.ID  = r.VariablesID
JOIN DataLayout dl         ON dl.ID = r.DataLayoutID
JOIN DataInterpretation di ON di.ID = r.DataInterpretationID
WHERE r.K_StepsID = 40 AND r.MeshEntityID = 336
ORDER BY dl.ID, v.Name;

查詢一定先給 K_StepsID

Result 的索引是 (K_StepsID, MeshEntityID, VariablesID)，條件從 K_StepsID 開始給，查詢在毫秒內完成；只用 VariablesID 或變數名稱查，SQLite 會掃過整張 3 GB 的表，要好幾秒到幾分鐘。

Data 裡的數字怎麼排：五種 DataLayout

解碼前要知道 Data 裡的數字各屬於哪個點。這由 DataLayoutID 決定：

DataLayout本檔筆數一包 Data 裡有幾個點排列順序典型的量
Unique Nodal（5）686,388這一塊的不重複節點數節點在連接表中第一次出現的順序（不是編號大小）Displacement、Phase Displacement
Integration Point（2）3,027,737元素數 × 12第 1 個元素的 12 個積分點，接著第 2 個元素…；座標見 StagedUserFeatureGlobalParameterDataEffective Stress、Plastic Point Information
Mesh Entity（3）1,891,4511整塊一個值Volume Change、Cluster Info
Nodal（1）81,647元素數 × 每元素節點數逐元素、逐節點；共用節點會重複出現Water Pressure（邊界線）
Element（4）76元件數每個元件一個值Prescribed Displacement（固定節點群）
只有 1 筆，代表整塊同一個值

Integration Point 的量，如果 Data 只有 8 bytes（1 個 Double），表示整個區塊每個積分點都是同一個值，例如 Young's Modulus、Cohesion。讀的時候要把它當成常數，不要以為資料不見。

Python：讀位移（Unique Nodal）並對到節點座標

Python
step = last_step(1)                      # L01 最後一步
ent = 336                                # 岩體區塊（MeshEntity.ID）
u = get_result(step, ent, 'Displacement', UNIQUE_NODAL)   # (n, 2)：ux, uy，單位 m
ids = unique_nodes(connectivity(ent))    # 這 n 列各屬於哪個節點
xy = node_xy()[ids - 1]                  # 節點編號從 1 起算，所以 -1

print('K_Steps.ID =', step, '，位移陣列形狀', u.shape, '，節點數', len(ids))
k = np.argmax(np.hypot(u[:, 0], u[:, 1]))
print(f'最大位移在節點 {ids[k]}，座標 ({xy[k, 0]:.2f}, {xy[k, 1]:.2f})')
print(f'ux = {u[k, 0] * 1000:.2f} mm，uy = {u[k, 1] * 1000:.2f} mm')

Python：讀積分點應力，並配上積分點座標

Python
step, ent = last_step(1), 336
s = get_result(step, ent, 'Effective Stress', INTEGRATION_POINT)     # (元素數×12, 4)

# 積分點座標存在 StagedUserFeatureGlobalParameterData（StressPoints），用同一個區塊去找
row = con.execute('''SELECT g.Data, g.DataInterpretationID, g.ComponentSize
                     FROM StagedUserFeatureGlobalParameterData g
                     JOIN StagedUserFeature f ON f.ID = g.StagedUserFeatureID
                     WHERE f.MeshEntityID = ? AND g.ComponentSize = 2''', (ent,)).fetchone()
pts = decode(*row)                                                  # (元素數×12, 2)

print('應力', s.shape, '；座標', pts.shape)
print('      x         y      σxx      σyy      σzz      σxy   (kPa，壓為負)')
for (x, y), (sxx, syy, szz, sxy) in list(zip(pts, s))[:5]:
    print(f'{x:7.2f} {y:9.2f} {sxx:8.1f} {syy:8.1f} {szz:8.1f} {sxy:8.1f}')

應力分量順序怎麼確認的

Effective Stress 的 4 個分量依序是 σxx、σyy、σzz、σxy。驗證方法：初始階段 Ph0 用 K0 程序產生地應力，剪應力應為 0；實測第 4 個分量在 Ph0 全部等於 0，且第 1、3 分量與第 2 分量的比值固定（0.485、0.356，即 K0）。

哪些步有完整結果

這個模型每個階段只保存最後一步（階段設定 Maximum Number Of Steps Saved = 1，見 PhaseParameterData）。中間的計算步只存「曲線點」所在的單一元素（auxiliary entity），用來畫荷載-位移曲線：

SQL（sqlite3 終端機或 Python 皆可）
SELECT k.Number AS 階段內第幾步, COUNT(*) AS 結果筆數,
       COUNT(DISTINCT r.MeshEntityID) AS 區塊數
FROM Result r JOIN K_Steps k ON k.ID = r.K_StepsID
WHERE k.I_PhaseID = 4 AND k.Number >= 33          -- I_PhaseID 4 = L01
GROUP BY k.Number;

單位與符號

  • 單位由 ProjectPropertiesData 的 Unit Factor 決定：長度 m、力 kN、時間 day，所以應力是 kPa、位移是 m。
  • 應力壓為負、拉為正（土壤力學習慣相反，畫圖時常要加負號）。
  • 本模型的地下水頭設在 −647.8 m，低於模型底部 −637.8 m，全區都在水位以上。Steady Pore Pressure 為正值，代表吸力；計算設定 Ignore Suction = 1，所以它不影響有效應力。
小測驗
想讀「L05 結束時，區塊 336 的 σyy」，下列哪個組合是對的？
K_StepsID 是全檔流水號，不是階段編號，要用 last_step(5) 換算；應力在積分點上（Integration Point），4 個分量依序 σxx、σyy、σzz、σxy，σyy 是第 2 欄，Python 索引 1。
1.2

GlobalResult

每一步「整個模型」的數字：ΣMstage、疊代次數、誤差、塑性點數…

筆數 164,985欄位 7

和 Result 很像，但不分網格區塊：每一步存一組描述「整個模型」的數字，例如這一步的 ΣMstage（施工進度 0→1）、疊代次數、整體誤差、塑性點數。對應 PLAXIS 計算視窗裡看到的那些數字。

ComponentSizeINTEGER NOT NULL分量數，大多是 1
CreatorIDFKINTEGER NOT NULL由哪個程式寫入 → Creator

VariablesIDFKINTEGER NOT NULL哪一種整體量，例如 SumMStage、Number of Iterations → Variables
DataInterpretationIDFKINTEGER NOT NULL數字格式。同一個量在中間步是 Float、在最後一步是 Double → DataInterpretation
DataBLOBBLOB NOT NULL數值（二進位）

Python：各施工階段結束時的整體資訊

Python
want = ['Global Step Number', 'SumMStage', 'Number of Iterations', 'Max Absolute Phase Displacement']
phases = [n for (n,) in con.execute('SELECT Number FROM I_Phase WHERE PhaseTypeID = 1 AND Number >= 1 ORDER BY Number')]

print('階段  總步號  ΣMstage  最後一步疊代  階段最大位移(mm)')
for num in phases:
    step = last_step(num)
    val = {}
    for name, data, di, cs in con.execute('''SELECT v.Name, g.Data, g.DataInterpretationID, g.ComponentSize
                                             FROM GlobalResult g JOIN Variables v ON v.ID = g.VariablesID
                                             WHERE g.K_StepsID = ?''', (step,)).fetchall():
        if name in want:
            val[name] = decode(data, di, cs)[0]
    print(f'L{num:02d}  {val["Global Step Number"]:6d}  {val["SumMStage"]:7.3f}  {val["Number of Iterations"]:10d}'
          f'  {val["Max Absolute Phase Displacement"] * 1000:14.2f}')
