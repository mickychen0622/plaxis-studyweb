施工階段

施工階段（Phase）與計算步（Step）是讀結果的時間座標。I_Phase 是階段清單，K_Steps 是每個階段裡的計算步，PhaseParameterData 是每個階段的計算設定。Result 用的 K_StepsID 要從這裡換算。

這一類要回答

這個模型有幾個施工階段？「L05 結束時」對應到哪一個 K_StepsID？

這一類的表

I_Phase37 筆K_Steps3,856 筆PhaseParameterData4,099 筆

Python 範例都接在 共用開頭 之後執行；下方「執行結果」是實際跑出來的輸出。

2.1

I_Phase

施工階段清單：編號、名稱、從哪個階段接續

筆數 37欄位 6

施工階段清單。37 筆裡只有 18 筆是真正的施工階段（PhaseTypeID = 1：Ph0 地應力平衡＋L01～L17 開挖），其餘是 PLAXIS 內部用的副本。

欄位型別意思
IDPKINTEGER流水號（其他表用這個）
NumberINTEGER NOT NULLPLAXIS 畫面上的階段編號：初始階段 0、L01 = 1 … L17 = 17；Unstaged = −1
NameTEXT NOT NULL階段名稱（PLAXIS 裡輸入的 ID）
ParentPhaseIDFKINTEGER從哪一個階段接續（Start from phase）；初始階段為 NULL → I_Phase
I_ProjectIDFKINTEGER NOT NULL所屬專案 → I_Project
PhaseTypeIDFKINTEGER NOT NULL1 = Main（真正的施工階段）、4 = Initial Condition、5 = Unstaged → PhaseType

37 筆的組成

SQL（sqlite3 終端機或 Python 皆可）
SELECT t.Description AS 階段類型, COUNT(*) AS 筆數,
       MIN(p.Number) AS 最小Number, MAX(p.Number) AS 最大Number
FROM I_Phase p JOIN PhaseType t ON t.ID = p.PhaseTypeID
GROUP BY t.ID;

Python：沿著 ParentPhaseID 走出施工順序

Python
info = {pid: (num, name, parent)
        for pid, num, name, parent in con.execute('SELECT ID, Number, Name, ParentPhaseID FROM I_Phase')}

pid = con.execute('SELECT ID FROM I_Phase WHERE Number = 17 AND PhaseTypeID = 1').fetchone()[0]
chain = []
while pid is not None:                   # 從 L17 一路往回找到初始階段
    num, name, parent = info[pid]
    chain.append(f'{num:2d}  {name}')
    pid = parent
print('\n'.join(reversed(chain)))

小測驗
I_Phase 有 37 筆，這個模型真正的施工階段有幾個？
只有 PhaseTypeID = 1（Main）是施工階段：Ph0 加 L01～L17 共 18 個。另外 18 筆是 Initial Condition 副本，1 筆是 Unstaged。
2.2

K_Steps

每個施工階段裡的計算步；Result 用的 K_StepsID 就是這裡的 ID

筆數 3,856欄位 3

每個施工階段裡的計算步（PLAXIS 計算視窗裡的 Step）。PLAXIS 用荷載增量把一個階段分成很多小步，每一步都在這裡留一列。

欄位型別意思
IDPKINTEGER全檔唯一的步編號；Result、GlobalResult 用的就是它
NumberINTEGER NOT NULL這個階段裡的第幾步，每個階段從 1 重新起算（Initial Condition、Unstaged 為 0）
I_PhaseIDFKINTEGER NOT NULL屬於哪個施工階段 → I_Phase
ID 和 Number 不一樣

Number 是「階段內第幾步」，每個階段都從 1 開始；ID 是整個檔案的流水號。Result 的 K_StepsID 對的是 ID。L01 的第 36 步，ID 是 40。

每個階段的最後一步

完整結果只存在每個階段的最後一步，所以最常用的查詢就是找出它的 ID：

SQL（sqlite3 終端機或 Python 皆可）
SELECT p.Number AS 階段, p.Name AS 名稱, MAX(k.Number) AS 步數,
       (SELECT k2.ID FROM K_Steps k2 WHERE k2.I_PhaseID = p.ID
         ORDER BY k2.Number DESC LIMIT 1) AS 最後一步的ID
FROM I_Phase p JOIN K_Steps k ON k.I_PhaseID = p.ID
WHERE p.PhaseTypeID = 1
GROUP BY p.ID ORDER BY p.Number;

2.3

PhaseParameterData

每個施工階段的計算設定：計算類型、步數上限、容許誤差…

筆數 4,099欄位 7

每個施工階段的計算設定，對應 PLAXIS「Phases」視窗裡的選項：計算類型、荷載輸入方式、最大步數、容許誤差、是否忽略吸力…。每個 Main 階段約 112 列。

欄位型別意思
IDPKINTEGER流水號
PhaseParameterIDFKINTEGER NOT NULL參數名稱 → PhaseParameter
CreatorIDFKINTEGER NOT NULL由哪個程式寫入 → Creator
ParentParameterDataIDFKINTEGER指向同一張表的另一列，用來分組，例如屬於「Deformation Calculation Data」群組 → PhaseParameterData
I_PhaseIDFKINTEGER NOT NULL哪個施工階段 → I_Phase
DataInterpretationIDFKINTEGER數值格式；PhaseParameterTableId 表示值是 PhaseParameter 的 ID（列舉值） → DataInterpretation
DataBLOBBLOB參數值（二進位）；群組列本身為 NULL

值是編號時：列舉值

像「計算類型」這種選項，Data 存的不是文字而是編號，格式標成 PhaseParameterTableId，數字就是 PhaseParameter 的 ID。例如 69 = Plastic Calculation、83 = Staged Construction Loading Type。PhaseParameter 同時當「參數名稱表」與「選項名稱表」用。

同名參數出現多次：看群組

SQL（sqlite3 終端機或 Python 皆可）
SELECT p.Description AS 參數, g.Description AS 所屬群組, di.Description AS 格式, hex(d.Data) AS 原始資料
FROM PhaseParameterData d
JOIN PhaseParameter p           ON p.ID  = d.PhaseParameterID
LEFT JOIN PhaseParameterData pd ON pd.ID = d.ParentParameterDataID
LEFT JOIN PhaseParameter g      ON g.ID  = pd.PhaseParameterID
LEFT JOIN DataInterpretation di ON di.ID = d.DataInterpretationID
WHERE d.I_PhaseID = 4 AND p.Description LIKE 'Maximum Number Of%';

Python：讀出 L01 的變形計算設定

Python
pid = con.execute('SELECT ID FROM I_Phase WHERE Number = 1 AND PhaseTypeID = 1').fetchone()[0]
names = dict(con.execute('SELECT ID, Description FROM PhaseParameter'))   # 參數名稱，也是列舉值名稱
rows = con.execute('''SELECT ID, PhaseParameterID, ParentParameterDataID, DataInterpretationID, Data
                      FROM PhaseParameterData WHERE I_PhaseID = ?''', (pid,)).fetchall()
group = {rid: names[ppid] for rid, ppid, *_ in rows}         # 本階段每一列的名稱，用來認群組

for rid, ppid, parent, di, data in rows:
    if data is None or group.get(parent) != 'Deformation Calculation Data':
        continue
    v = decode(data, di)[0]
    if di == 14:                       # PhaseParameterTableId → 換成選項名稱
        v = names[int(v)]
    print(f'{names[ppid]:38s} {v}')
