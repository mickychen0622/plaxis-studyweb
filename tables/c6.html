6.3

ProjectPropertiesData

專案整體設定：重力、單位、分析類型、元素類型

筆數 32欄位 5

專案的整體設定，對應 PLAXIS「Project properties」視窗：重力、水的單位重、模型範圍、單位、分析類型、元素類型…

欄位型別意思
IDPKINTEGER流水號
ProjectPropertiesIDFKINTEGER NOT NULL哪個設定項目 → ProjectProperties
I_ProjectIDFKINTEGER NOT NULL所屬專案 → I_Project
DataInterpretationIDFKINTEGER NOT NULL數值格式；ProjectPropertiesTableId 表示值是 ProjectProperties 的 ID → DataInterpretation
DataBLOBBLOB設定值（二進位）

Python：讀出全部設定

Python
names = dict(con.execute('SELECT ID, Description FROM ProjectProperties'))
for pid, di, data in con.execute('SELECT ProjectPropertiesID, DataInterpretationID, Data FROM ProjectPropertiesData ORDER BY ID'):
    v = decode(data, di)
    if di == 17:                                   # ProjectPropertiesTableId → 選項名稱
        v = names[int(v[0])]
    elif v is not None:
        v = v[0] if len(v) == 1 else v.tolist()
    print(f'{names[pid]:52s} {v}')
