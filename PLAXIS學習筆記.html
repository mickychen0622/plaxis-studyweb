第一部

PLAXIS 計算原理

1.1 從平衡方程到有限元素

土體靜力平衡寫成微分方程（強形式）：每一點的應力散度加上體積力等於零。真實的幾何、材料介面與非線性組成律讓它沒有解析解，所以改成「平均平衡」的弱形式，再離散成矩陣方程。

三個基本關係

關係式子意義
平衡\(L^{T}\sigma + b = 0\)應力的空間導數與體積力 \(b\) 平衡
相容\(\varepsilon = L\,u\)應變是位移的導數
組成律\(\dot\sigma = M\,\dot\varepsilon\)應力率與應變率的關係，MC 就在這裡進來

弱形式：虛功方程

平衡式乘上任意容許的虛位移 \(\delta u\) 後積分，再做分部積分，得到虛功方程。左邊是內虛功，右邊是體積力與邊界曳力 \(t\) 做的外虛功：

\[ \int \delta\varepsilon^{T}\sigma\,dV = \int \delta u^{T} b\,dV + \int \delta u^{T} t\,dS \]

應力以增量方式發展：\(\sigma^{i} = \sigma^{i-1} + \Delta\sigma\)。上一步的應力 \(\sigma^{i-1}\) 已知，要求的是這一步的增量 \(\Delta\sigma\)。

離散化

元素內的位移由節點位移 \(v\) 內插：\(u = N v\)，應變 \(\varepsilon = B v\)，其中 \(B\) 是形狀函數的導數。代入虛功方程，消去任意的 \(\delta v\)，得到：

\[ \underbrace{\int B^{T}\Delta\sigma\,dV}_{\text{本步要求的應力增量}} = \underbrace{\int N^{T} b^{i}\,dV + \int N^{T} t^{i}\,dS}_{\text{目前的外力 } f_{ex}^{i}} - \underbrace{\int B^{T}\sigma^{i-1}\,dV}_{\text{上一步的內力 } f_{in}^{i-1}} \]
重點外力與內力的差，就是要靠應力增量去平衡的不平衡力（out-of-balance force）。PLAXIS 的所有計算都圍繞這個量。

元素與應力點

元素位移內插應力點（Gauss 點）數使用時機
15 節點三角形四次12PLAXIS 2D 預設；應力與破壞載重較準，適合破壞問題與不排水分析
6 節點三角形二次3計算較快；同樣元素數時精度較低，不排水或破壞問題偏硬

組成律只在應力點上計算。Output 裡平滑的應力等值線是由應力點外插到節點、再取平均得到的，看塑性區時要回到應力點本身（Plastic points）。

1.2 Step 與 Iteration：整體迭代

土壤的應力–應變關係是非線性的，勁度事先不知道，所以每一個 step 都要迭代。第 \(i\) 步的第 \(j\) 次迭代：

\[ K\,\delta v^{j} = f_{ex}^{i} - f_{in}^{j-1}, \qquad \Delta v^{i} = \sum_{j=1}^{n}\delta v^{j} \]

\(\delta v^{j}\) 是這次迭代的位移修正，累加起來就是這一步的位移增量。勁度矩陣 \(K\) 越接近真實的材料行為，需要的迭代次數越少。

PLAXIS 用彈性勁度矩陣迭代

\[ K = \int B^{T} D^{e} B\,dV \]
  • 只要材料勁度不增加，用彈性勁度矩陣迭代都很穩健，非關聯塑性也一樣。
  • MC 在彈性範圍內是線性的，勁度矩陣只要在第一步之前組成並分解一次，之後每次迭代只做回代，這是 MC 計算快的原因。
  • 這種做法稱為加速初始應力法（accelerated initial stress method）。程式另外用下列技巧減少迭代次數。
技巧做法預設
Over-relaxation刻意把每次的修正量放大，因為只解掉「目前的不平衡」通常還離平衡很遠1.2（理論上限 2.0；φ < 20° 時約 1.5 最佳，φ 高時要更小）
Extrapolation同一種載重延續到下一步時，用上一步的位移解當第一次估計，比彈性預測更接近適用時自動使用
Arc-length control接近破壞時自動調整載重比例，可以越過極限點（見 1.5）開啟
Subspace accelerator以 modified Newton-Raphson 為基礎，再用前幾次迭代的位移增量（Krylov 子空間）加速；對局部破壞等強非線性問題最有效子空間大小 3
Line search每次迭代自動決定修正量的縮放比例；適合非線性不嚴重的使用性分析，破壞類問題通常不會更快依版本設定
Gradual error reduction容許誤差從 10 倍開始，到 phase 結束時線性降回設定值；用於非關聯流動收斂很慢時，建議同時把 Max load fraction per step 調小關閉

一個 step 的完整流程

  1. 形成勁度矩陣 \(K=\int B^{T}D^{e}B\,dV\) 並分解（MC 只做一次）
  2. 新的一步：外力向量加上本步增量 \(f_{ex}^{i} = f_{ex}^{i-1} + \Delta f_{ex}\)
  3. 計算內力 \(f_{in} = \int B^{T}\sigma^{i-1}dV\) 與不平衡力 \(\Delta f = f_{ex}^{i}-f_{in}\)；位移增量歸零
  4. 迭代：解 \(\delta v = K^{-1}\Delta f\)，累加位移增量 \(\Delta v\)
  5. 由位移算應變增量 \(\Delta\varepsilon = B\Delta v\)
  6. 每個應力點：試算應力 \(\sigma^{tr}=\sigma^{i-1}+D^{e}\Delta\varepsilon\)，超出降伏面就回傳（1.3 節）
  7. 由新應力算內力 \(f_{in}=\int B^{T}\sigma\,dV\)，得到新的不平衡力
  8. 檢查誤差：未達標準就回到第 4 項繼續迭代
  9. 收斂：更新總位移、寫出結果；ΣMstage 未到 1 就進入下一步

1.3 應力點上的回傳計算

整體迭代給每個應力點一個應變增量 \(\Delta\varepsilon\)，組成律要把它換成應力增量。PLAXIS 採隱式積分（implicit，又稱後退 Euler 或回傳法，return mapping）：

\[ \Delta\sigma = D^{e}\left(\Delta\varepsilon - \Delta\varepsilon^{p}\right), \qquad \Delta\varepsilon^{p} = \Delta\lambda \left(\frac{\partial g}{\partial \sigma}\right)^{i} \]

塑性應變的方向取在本步終點的應力上。好處是不必先找出「彈性轉塑性」的交點，而且在一定條件下會得到對稱正定的矩陣，對迭代有利。

步驟一：彈性試算

\[ \sigma^{tr} = \sigma^{i-1} + D^{e}\Delta\varepsilon \]

步驟二：塑性修正（只在 \(f(\sigma^{tr})>0\) 時）

\[ \sigma^{i} = \sigma^{tr} - \frac{\langle f(\sigma^{tr})\rangle}{d+h}\,D^{e}\left(\frac{\partial g}{\partial\sigma}\right)^{i} \]
\[ d = \left(\frac{\partial f}{\partial\sigma}\right)^{tr}{}^{T} D^{e}\left(\frac{\partial g}{\partial\sigma}\right)^{i} \]

\(\langle x\rangle\) 是 McCauley 括號：\(x\le 0\) 時為 0，\(x>0\) 時為 \(x\)。\(h\) 是硬化參數，MC 為完全塑性，\(h = 0\)。

MC 的角點MC 的降伏面由六個平面組成，兩個平面相交處（角點）的法線方向不唯一。PLAXIS 不把角點修圓，而是用精確的尖角形式：應力回到角點時，同時啟用兩個塑性勢函數（Koiter 多勢函數法則，見 2.4 節）。加上 tension cut-off 後，還會出現「受拉角點」與「apex 點」，這些點的回傳比平邊上困難，數量多時迭代會變慢。

1.4 收斂判準

每次迭代後，PLAXIS 同時檢查整體與局部兩類誤差，兩者都低於容許值才算這一步收斂。

整體誤差（Global error）

用不平衡節點力的大小，除以本階段的荷載做無因次化：

\[ \text{Global error} = \frac{\lVert f_{ex}-f_{in}\rVert}{\lVert f_{active}\rVert + \text{CSP}\cdot\lVert f_{inactive}\rVert} \le \text{Tolerated error}\;(\text{預設 }0.01) \]
  • Active loads：本階段與前一階段的荷載差。ΣMstage = 0 時就等於不平衡力本身。
  • Inactive loads：前面各階段已經施加的荷載。
  • CSP（Current Stiffness Parameter，畫面上的 Stiffness）：
\[ \text{CSP} = \frac{\int \Delta\varepsilon^{T}\Delta\sigma\,dV}{\int \Delta\varepsilon^{T}D^{e}\Delta\varepsilon\,dV} \]

全彈性時 CSP = 1，接近破壞時趨近 0。CSP 越小，分母越小，同樣的不平衡力算出來的誤差越大，所以塑性越多，判準反而越嚴。

局部誤差（不準確塑性點）

每個塑性應力點比較兩種應力：整體線性化後的「平衡應力」\(\sigma_{eq}\)，以及組成律真正算出的「組成應力」\(\sigma_{c}\)：

\[ \text{Local error}_{j} = \frac{\lVert\sigma_{eq,j}-\sigma_{c,j}\rVert}{\max(\tau_{max,j},\;c,\;1\,\text{kPa})} \]

局部誤差大於 Tolerated error 的點稱為不準確（Inaccurate）塑性點。容許的不準確點數為：

\[ N_{\text{inaccurate}} < 0.1\times N_{\text{plastic}} + 3 \]

介面元素另外計算一組，判準相同。例如 7259 個塑性點，容許 0.1 × 7259 + 3 ≈ 729 個不準確點，這就是 Active tasks 視窗 Tolerated 欄顯示的數字。

容許誤差不要隨便放大Tolerated error 設得比 0.01 大，計算會變快，但結果可能根本不平衡。如果破壞載重隨位移增加反而意外下降，常是誤差累積造成的漂移，應該用更小的容許誤差重算。

1.5 自動步長與 Arc-length

步長怎麼調整

第一步的大小由試算決定。之後每一步依收斂所需的迭代次數調整：

情況判斷處理
迭代次數 < Desired min（預設 6）步長太小載重增量 × 2，繼續迭代
迭代次數 > Desired max（預設 15）仍未收斂步長太大載重增量 ÷ 2，繼續迭代
介於兩者之間步長合適下一步沿用這個步長

為什麼需要 Arc-length

關掉 Arc-length 時程式不能採用負的步長。結構其實正在破壞時，計算可能只是一直停在某個 ΣMstage 附近。這時要看最後一步的變形，自己判斷是否在破壞，提高 Max steps 重算是沒有用的。

1.6 分階施工與 ΣMstage

每個 phase 在 Staged construction 模式中定義新的狀態：啟用或停用土體群（cluster）與結構物、改變荷載、更換材料、改變水壓。程式比較「本階段結束時應有的狀態」與「上一階段結束時的狀態」，把兩者的差異分成多個 step 解掉。

停用與啟用元素的規則

停用（開挖）的元素
  • 重量、勁度、強度都不再計入
  • 應力設為零，節點位移為零
  • 新產生的邊界自動成為自由、透水邊界
  • 水的條件會保留；要模擬乾式開挖，需另外修改該群的水條件
  • 作用在已停用區域上的外力不計入
啟用（回填、新建）的元素
  • 勁度與強度從本階段第一步就完全計入
  • 重量原則上也從第一步計入，因此一開始會有很大的不平衡力，再分步解掉
  • 應力從零開始
  • 新節點先以無應力的方式貼合已變形的網格，再累加之後的位移

ΣMstage 的意義

  • 每個 phase 開始時 ΣMstage = 0，成功結束時等於 1.000，表示不平衡力已經全部解掉。
  • 可以刻意把目標設成小於 1，例如連續三個 phase 分別設 0.5、0.5、1.0：
    • 第一個 phase 結束：解掉 50% 的不平衡力
    • 第二個 phase 結束：再解掉剩下的 50%，累計 75%
    • 第三個 phase 結束：累計 100%
  • ΣMstage < 1 結束的 phase 仍留有不平衡力，後面一定要接另一個 Staged construction phase。ΣMstage 到 1 之前，不要做其他類型的計算（例如 Safety）。

ΣMstage 沒有到 1：三種原因

原因怎麼判斷怎麼處理
使用者把 ΣMstage 目標設成 < 1這是刻意的設定下一個 phase 會繼續解剩下的不平衡力
土體破壞Stiffness（CSP）趨近 0、位移暴增、ΣMstage 停滯或下降從這個 phase 繼續算沒有意義；要檢查支撐、參數、開挖順序
步數不夠ΣMstage 仍在穩定上升，CSP 還不小提高 Max steps 重算，或接一個不改變任何設定的 phase 繼續算

沒完成的 phase 實際施加的荷載可以估算為：\(f_{applied} = f_{0} + \Sigma M_{stage}\,(f_{defined}-f_{0})\)。

Deconfinement 與 ΣMstage < 1 的差別

隧道分析常用 β 法（收斂–圍束法）模擬開挖面的三維拱效應：開挖時先只釋放 (1−β) 的應力，等支撐裝上後再釋放剩下的 β。PLAXIS 有兩種做法：

ΣMstage < 1Deconfinement
設定位置Phase 的 General 參數在 Staged construction 中逐一設定每個 soil cluster，輸入百分比 (1−β)
作用對象整個 phase 的總應力變化，有效應力與孔隙水壓同等影響只影響有效應力變化，不影響水壓變化
多洞室所有變化共用一個比例每個開挖段可以用不同的釋放比例

Deconfinement 的流程：產生初始應力 → 停用隧道群，設定 Deconfinement = 1−β → 啟用襯砌，並把洞內群的 Deconfinement 設為 100%。

1.7 初始應力

土層在施工前已經在自重下平衡，帶著完整的應力場。初始應力錯了，後面每個階段都跟著錯。Initial phase 有三種計算類型：

方法做法適用注意
K0 procedure垂直應力 = 上覆重量；水平應力 = K0 × 垂直應力。不檢查平衡地表、土層與水位都水平不產生剪應力，地表傾斜時會有不平衡力；K0 太大或太小會使應力超出 MC 降伏面，程式會自動降低水平應力，產生塑性點
Gravity loading以 Plastic 計算施加自重（ΣMweight 0 → 1）地表傾斜、地層不水平MC 下 K0 由 ν 決定：\(K_0=\nu/(1-\nu)\)，難以得到 K0 > 1；下一階段要 Reset displacements to zero
Field stress直接指定三個主應力與主方向，整個模型為均勻應力深層岩體、主應力有旋轉不考慮應力隨深度增加，ΣMweight 固定為 0，後續階段也要維持 0；四邊界都要全固定；之後要接 nil-phase
  • Plastic nil-phase：一個不加任何荷載的 Plastic phase，用來解掉 K0 procedure 留下的少量不平衡或塑性點。離平衡太遠時（例如陡坡）nil-phase 也會不收斂，要改用 Gravity loading。
  • Reset displacements to zero：初始應力產生的位移沒有物理意義，下一個 phase 要勾選，讓位移從零開始累計。應力不受影響。
  • MC 材料用 K0 procedure 時，K0 預設為 Jaky 公式 \(1-\sin\varphi'\)，要指定其他值時在材料的 Initial 頁改成 Manual（見 3.5 節）。
  • 無凝聚性材料要避免初始應力就降伏，K0 必須介於 \(\dfrac{1-\sin\varphi}{1+\sin\varphi}\) 與 \(\dfrac{1+\sin\varphi}{1-\sin\varphi}\) 之間。

1.8 Safety（強度折減）

Safety 計算回答「目前這個狀態下，強度還能打幾折才會破壞」。荷載、幾何與勁度都不變，只用同一個係數 ΣMsf 逐步折減強度：

\[ \Sigma M_{sf} = \frac{\tan\varphi_{input}}{\tan\varphi_{reduced}} = \frac{c_{input}}{c_{reduced}} \]
  • tanφ、c 與抗拉強度同時折減；介面強度用同樣方式折減。
  • 膨脹角 ψ 原則上不折減。但 ψ 不能大於 φ，φ 降到等於 ψ 之後，ψ 會跟著 φ 一起降。
  • Plate、Anchor 等結構物可以用 Enhanced safety analysis 一起折減（限彈塑性結構），也可以排除特定土體群，避免出現不合理的淺層破壞。

設定與判讀

  • Calculation type 選 Safety，Loading type 用 Incremental multipliers，第一步增量 Msf 預設 0.1。
  • Safety 會跑滿 Max steps（預設 100），不會因為破壞而停。最後一定要用 Curves 確認 ΣMsf 已經出現平台，沒有平台就加大步數重算。
  • 要用 Arc-length control，容許誤差不超過 1%（預設值即符合）。沒有 Arc-length 時 ΣMsf 不能下降，可能高估安全係數。
  • 網格要夠細才能正確捕捉破壞機制。
  • Safety phase 的位移沒有物理意義，建議勾選 Reset displacements to zero，也不要拿它接後續施工階段。
  • 結果與極限平衡法的滑弧分析相近。
強度折減找到的機制強度折減找到的是「強度下降時最先破壞的機制」，不一定等於「荷載增加時最先破壞的機制」。兩種安全係數可能不同，報告時要寫明用的是哪一種。進階模型在 Safety 中會退化成 MC 行為（勁度固定在 phase 開始時的值，不再硬化）。Hoek-Brown 材料有自己的折減公式，得到的 FS 與等值 MC 參數的 FS 不同。

第二部

Mohr-Coulomb 組成律

2.1 線彈性–完全塑性

MC 是線彈性–完全塑性模型：

  • 彈性段：等向線彈性的 Hooke 定律，參數 E、ν，E 不隨應力改變。
  • 塑性段：Mohr-Coulomb 破壞準則，採非關聯流動。
  • 完全塑性：降伏面固定，只由參數決定，不隨塑性應變改變，沒有硬化也沒有軟化。

應變分成彈性與塑性兩部分，只有彈性應變產生應力：

\[ \varepsilon = \varepsilon^{e} + \varepsilon^{p}, \qquad \dot\sigma' = D^{e}\left(\dot\varepsilon - \dot\varepsilon^{p}\right) \]

塑性組成律的四個要素

要素回答的問題MC 的答案
彈性降伏前怎麼變形Hooke 定律，E、ν 為常數
降伏面 f = 0彈性與塑性的分界六個平面圍成的六角錐（2.3 節）
流動法則塑性應變往哪個方向非關聯：塑性勢 g 用膨脹角 ψ（2.4 節）
硬化法則降伏面會不會隨塑性應變改變沒有，完全塑性

彈性參數之間的換算

\[ G=\frac{E}{2(1+\nu)},\qquad K=\frac{E}{3(1-2\nu)},\qquad E_{oed}=\frac{(1-\nu)E}{(1-2\nu)(1+\nu)},\qquad K_0^{\text{(一維壓縮)}}=\frac{\nu}{1-\nu} \]

2.2 應力的描述與符號

一點的應力張量對稱，有 6 個獨立分量。轉到沒有剪應力的方向，得到三個主應力。等向材料的組成律只需要主應力的大小（加上方向）。

量定義（壓為正）物理意義
平均應力 p′\((\sigma_1'+\sigma_2'+\sigma_3')/3\)管體積（擠壓）
偏應力 q\(\sqrt{\tfrac12\left[(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2\right]}\)；三軸時 \(=\sigma_1-\sigma_3\)管形狀（剪切）
Mohr 圓圓心 s\((\sigma_1'+\sigma_3')/2\)MC 只用最大與最小主應力
Mohr 圓半徑 t\((\sigma_1'-\sigma_3')/2\)最大剪應力
Lode 角 θπ 平面上的方向角區分三軸壓縮（σ1 為軸向最大）與三軸伸張（軸向最小）
符號慣例土壤力學教科書與本頁原理部分採壓為正。PLAXIS 的輸入與輸出採拉為正、壓為負：Output 中的有效應力多半是負值，σ′1 是「最大壓應力」也就是數值最小（最負）的那一個。讀 PLAXIS 的公式與結果時要先換號。

2.3 降伏面

Mohr 圓與庫倫摩擦

Mohr 圓與破壞線 \(\tau = c + \sigma_n\tan\varphi\) 相切時發生破壞。用主應力寫成（壓為正）：

\[ f = \frac{\sigma_1'-\sigma_3'}{2} - \frac{\sigma_1'+\sigma_3'}{2}\sin\varphi - c\cos\varphi \le 0 \]

等價的主應力比形式：

\[ \sigma_{1f}' = N_\varphi\,\sigma_3' + 2c\sqrt{N_\varphi},\qquad N_\varphi=\frac{1+\sin\varphi}{1-\sin\varphi} \]
導出量式子說明
單軸抗壓強度\(\sigma_{cm} = \dfrac{2c\cos\varphi}{1-\sin\varphi}=2c\sqrt{N_\varphi}\)σ3 = 0 時的 σ1
MC 隱含的單軸抗拉強度\(\dfrac{2c\cos\varphi}{1+\sin\varphi}\)c 越大越大，常高於實際，所以要 tension cut-off
錐頂（等向受拉）\(\sigma_1'=\sigma_3' = -c\cot\varphi\)c > 0 時錐頂在受拉側

σ2 不出現在式子裡。MC 只看最大和最小主應力，σ2 的影響要在 π 平面上才看得到。

PLAXIS 中的六個降伏函數

一般應力狀態下，主應力的大小順序不固定，所以把準則套用到每一對主應力（含順序對調），得到六個降伏函數。PLAXIS 採拉為正，寫成：

\[ \begin{aligned} f_{1a} &= \tfrac12(\sigma_2'-\sigma_3') + \tfrac12(\sigma_2'+\sigma_3')\sin\varphi - c\cos\varphi \le 0 \\ f_{1b} &= \tfrac12(\sigma_3'-\sigma_2') + \tfrac12(\sigma_3'+\sigma_2')\sin\varphi - c\cos\varphi \le 0 \\ f_{2a} &= \tfrac12(\sigma_3'-\sigma_1') + \tfrac12(\sigma_3'+\sigma_1')\sin\varphi - c\cos\varphi \le 0 \\ f_{2b} &= \tfrac12(\sigma_1'-\sigma_3') + \tfrac12(\sigma_1'+\sigma_3')\sin\varphi - c\cos\varphi \le 0 \\ f_{3a} &= \tfrac12(\sigma_1'-\sigma_2') + \tfrac12(\sigma_1'+\sigma_2')\sin\varphi - c\cos\varphi \le 0 \\ f_{3b} &= \tfrac12(\sigma_2'-\sigma_1') + \tfrac12(\sigma_2'+\sigma_1')\sin\varphi - c\cos\varphi \le 0 \end{aligned} \]

六個 \(f_i = 0\) 一起在主應力空間圍成一個固定的六角錐，錐軸是靜水壓軸。

Tension cut-off

c > 0 時 MC 容許拉應力，而且容許值隨 c 增加，這對土壤與節理岩體往往不實際。PLAXIS 另外加三個降伏函數（拉為正）：

\[ f_4=\sigma_1'-\sigma_t\le0,\qquad f_5=\sigma_2'-\sigma_t\le0,\qquad f_6=\sigma_3'-\sigma_t\le0 \]

也就是不容許任何主應力的拉應力超過 σt。這三個函數採關聯流動。MC 材料預設開啟 tension cut-off，σt = 0。

π 平面與 p–q 平面

三軸壓縮與三軸伸張的 σ1/σ3 都等於 Nφ，但 σ2 的位置不同，所以在 p–q 平面是兩條斜率不同的線（c = 0 時）：

\[ M_c=\frac{6\sin\varphi}{3-\sin\varphi},\qquad M_e=\frac{6\sin\varphi}{3+\sin\varphi} \]

π 平面上伸張與壓縮的半徑比：

\[ \frac{r_e}{r_c}=\frac{3-\sin\varphi}{3+\sin\varphi} \]

φ = 30° 時 Mc = 1.2、Me = 0.857、re/rc = 0.714。若用 Drucker-Prager 圓通過壓縮角，伸張強度會高估約 1.4 倍。

c > 0 時，兩條線改成 \(q = M\,(p' + c\cot\varphi)\)，與 p 軸交在受拉側的錐頂。

錐面沿 p 軸方向開放：單純等向加壓永遠不會降伏。

2.4 流動法則與膨脹角

塑性應變率等於塑性乘數乘上塑性勢的梯度：

\[ \dot\varepsilon^{p} = \lambda\,\frac{\partial g}{\partial\sigma'} \]
狀態條件λ
彈性\(f<0\)，或 \(f=0\) 但 \(\left(\partial f/\partial\sigma'\right)^{T}D^{e}\dot\varepsilon\le0\)（往面內卸載）λ = 0
塑性\(f=0\) 且 \(\left(\partial f/\partial\sigma'\right)^{T}D^{e}\dot\varepsilon>0\)（繼續往外推）λ > 0

持續降伏時應力點必須留在降伏面上（一致性條件 \(\dot f = 0\)），λ 由這個條件求出。MC 的面不會動，所以應力停住、應變持續增加。

關聯與非關聯

若 g = f（關聯流動），塑性應變垂直於降伏面。對 MC 而言，這會高估膨脹：剪動時體積一直以固定比例膨脹，在受圍束的問題中會提高圍壓、高估承載力。所以 PLAXIS 的 MC 另外定義塑性勢，把 φ 換成膨脹角 ψ，並去掉 c 項：

\[ g = \frac{\sigma_1'-\sigma_3'}{2} - \frac{\sigma_1'+\sigma_3'}{2}\sin\psi \quad(\text{壓為正，另外五個同理}) \]

ψ 決定剪脹比

對上式微分，塑性體積應變與塑性剪應變之比為：

\[ \frac{\dot\varepsilon_v^{p}}{\dot\gamma^{p}} = -\sin\psi\qquad(\dot\gamma^{p}=\dot\varepsilon_1^{p}-\dot\varepsilon_3^{p}) \]
  • ψ = 0：塑性流動不改變體積。
  • ψ > 0：只要持續剪動就一直膨脹。MC 沒有 dilatancy cut-off（只有 HS、HSsmall 有），不會在臨界狀態停止。
  • ψ ≠ φ 時彈塑性勁度矩陣不對稱（2.5 節）。

角點的處理

上面的塑性理論只適用光滑的降伏面。MC 是多面組成的，應力落在兩個面的交線（角點）時，法線方向是一個扇形而不是唯一方向。三軸壓縮與三軸伸張剛好都在角點上。處理方式有兩種：

做法內容
多勢函數（Koiter 法則）\(\dot\varepsilon^{p}=\lambda_1\,\partial g_1/\partial\sigma' + \lambda_2\,\partial g_2/\partial\sigma' + \dots\)，各個 λ 由對應的降伏函數決定。PLAXIS 用這種精確的尖角做法
角點修圓用平滑曲線取代尖角（如 Abbo-Sloan 雙曲線近似），回傳計算較穩定，但與原本的 MC 略有差異

2.5 彈塑性勁度矩陣

結合一致性條件，可以寫出應力率與應變率的關係：

\[ \dot\sigma' = \left(D^{e} - \frac{\alpha}{d}\,D^{e}\frac{\partial g}{\partial\sigma'}\frac{\partial f}{\partial\sigma'}^{T}D^{e}\right)\dot\varepsilon,\qquad d = \frac{\partial f}{\partial\sigma'}^{T}D^{e}\frac{\partial g}{\partial\sigma'} \]

α 是開關：彈性時 α = 0，塑性時 α = 1。括號內就是彈塑性勁度 \(D^{ep}\)。

  • g ≠ f 時，\(\partial g/\partial\sigma'\) 與 \(\partial f/\partial\sigma'\) 不同，\(D^{ep}\) 不對稱。用它組整體勁度要換成非對稱解法，成本大約加倍。
  • PLAXIS 的 MC 計算不用 \(D^{ep}\) 組勁度，而是一直用彈性勁度 \(D^{e}\) 迭代（1.2 節），所以不受非對稱影響，代價是迭代次數較多。

2.6 互動：Mohr 圓試算

輸入強度參數與一組主應力，看應力狀態相對於 MC 包絡線與 tension cut-off 的位置。這裡採壓為正，單位 kPa。預設值為 E = 15 GPa 岩體的一組研究參數。

3.2 勁度參數

E 要選哪一個

  • E0：初始切線模數。線彈性範圍大的材料用它。
  • E50：50% 強度處的割線模數。一般加載問題用它。
  • Eur：卸載–再加載模數。開挖、隧道屬於卸載問題，應該用 Eur。

土壤的勁度會隨圍壓增加、隨應力路徑改變，但 MC 的 E 是常數，所以要選一個與應力水準、應力路徑一致的值。Undrained (A)(B) 時輸入的是有效 E′，PLAXIS 會自動處理不可壓縮性。

ν 與 K0

  • 一維壓縮下 MC 給出 \(K_0=\nu/(1-\nu)\)，所以常用 K0 反算 ν，多半落在 0.3–0.4。這種方式無法得到 K0 > 1（高度過壓密）。
  • 卸載問題（開挖）取 0.15–0.25 較適當。
  • Undrained (A)(B) 時 ν′ 要小於 0.35，確保土骨架比孔隙水更容易壓縮。

G、Eoed 與波速

輸入 G 或 Eoed 中的任一個，程式會換算出 E，ν 保持不變。動力分析時勁度要能正確預測波速，通常要用小應變勁度，而不是工程應變下的勁度。

勁度隨深度增加

\[ E(y) = E_{ref} + (y_{ref}-y)\,E_{inc}\qquad (y<y_{ref}) \]

yref 以上 E = Eref。這個值只隨深度變化，計算中不會隨應力狀態改變。

3.3 強度參數

c 或 su

  • c′ 配 φ′：Drained 或 Undrained (A)，做有效應力分析。優點是壓密後強度會自動增加。
  • su 配 φ = 0：Undrained (B)(C)，MC 退化為 Tresca 準則。優點是能直接控制剪力強度，不受應力路徑影響。
  • Undrained (A) 用 c′、φ′ 時，模型給出的不排水強度可能和實際不同，建議每個階段都檢查 \(|\sigma_1-\sigma_3|\le 2s_u\)。
  • c = 0 可以算，但某些選項表現不好，建議近地表層至少給 0.2 kPa。
  • cinc：凝聚力隨深度增加，\(c(y)=c_{ref}+(y_{ref}-y)c_{inc}\)。φ′ > 0 時摩擦力已會讓強度隨深度增加，通常不需要。

φ

  • 黏土、粉土約 20–30°（塑性越高越低），砂礫約 30–40°（越密越高）。
  • φ 高時塑性計算量明顯增加，大變形下也可能軟化，初步計算應避免太高的 φ。

ψ

  • 黏土除了重度過壓密者外 ψ ≈ 0；石英砂 ψ ≈ φ − 30°，φ < 30° 時取 0；負值只適用極鬆砂。
  • Undrained (B)(C) 時 ψ 自動設為 0。
  • Undrained (A) 配 ψ > 0 時，體積不能變化，剪脹會產生拉的孔隙應力，使強度無限增加。必須開啟 cavitation cut-off（預設 100 kPa）限制。

σt

  • 預設勾選 Tension cut-off、σt = 0；可以在 Depth-dependency 區塊取消。
  • 岩體可依 Hoek-Brown 換算 \(\sigma_t = s\,\sigma_{ci}/m_b\) 給非零值。

3.4 排水類型

Drainage type勁度參數強度參數說明
DrainedE′、ν′c′、φ′、ψ不產生超額孔隙水壓；長期行為
Undrained (A)E′、ν′（有效）c′、φ′、ψ（有效）有效應力分析，程式疊加孔隙水的體積勁度；不排水強度是計算結果
Undrained (B)E′、ν′（有效）su，φ = 0，ψ = 0勁度用有效參數，強度直接用 su

Non-porousE、νc、φ、ψ無孔隙水，例如混凝土或完整岩體

Undrained (A)(B) 時，程式在土骨架上疊加孔隙水的等效體積勁度：

\[ \frac{K_{w,ref}}{n} = \frac{3(\nu_u-\nu')}{(1-2\nu_u)(1+\nu')}\,K',\qquad K'=\frac{E'}{3(1-2\nu')} \]

νu 預設 0.495，不可取 0.5，否則 Kw → ∞。對應的 Skempton B 值為 \(B = \dfrac{3(\nu_u-\nu')}{(1+\nu_u)(1-2\nu')}\)。

3.6 洞室與岩體的選值

參數洞室分析的選值要點
E開挖屬卸載，用 Eur 或岩體變形模數；E 不隨應力改變，可用 Einc 隨深度增加
ν卸載問題取 0.15–0.25。K0 = ν/(1−ν) 無法得到 K0 > 1，高 K0 要在初始應力階段另外指定
c、φ岩體可由 Hoek-Brown 換算等值 c′、φ′；換算時的應力範圍要與洞周圍壓一致
ψ用試驗值，或取 0.25φ 左右；MC 沒有 dilatancy cut-off
σt預設 0；岩體可依 Hoek-Brown 的 \(\sigma_t = s\,\sigma_{ci}/m_b\) 設定

Hoek-Brown 換算為等值 MC

岩石的勁度可視為常數，這點 MC 適用；但強度隨圍壓呈非線性，大範圍應力下 MC 的直線包絡不夠。可以在指定的圍壓範圍 \(-\sigma_t < \sigma_3' < \sigma_{3,max}'\) 內做平衡擬合：

\[ \sin\varphi' = \frac{6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}}{2(1+a)(2+a)+6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}} \]
\[ c' = \frac{\sigma_{ci}\left[(1+2a)s+(1-a)m_b\sigma_{3n}'\right](s+m_b\sigma_{3n}')^{a-1}}{(1+a)(2+a)\sqrt{1+\dfrac{6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}}{(1+a)(2+a)}}},\qquad \sigma_{3n}'=\frac{\sigma_{3,max}'}{\sigma_{ci}} \]

σ′3,max 依應用而定（例如洞周的最大圍壓）。擬合範圍不同，得到的 c′、φ′ 也不同。用等值 MC 做 Safety 得到的安全係數，和直接用 Hoek-Brown 做 Safety 的結果不會相同。

3.7 輸出：塑性點怎麼看

Output 的 Stresses → Plastic points 顯示處於塑性狀態的應力點，畫在未變形的網格上：

符號意義MC 會出現嗎
紅色方塊（Failure point）應力落在破壞包絡上會
白色方塊（Tension cut-off point）觸發 tension cut-off會（開啟 cut-off 時）
藍色倒金字塔（Cap point）正常壓密，應力等於預壓密應力不會
綠色金字塔（Hardening point）剪力硬化包絡上不會
棕色菱形（Cap + Hardening）同時在帽蓋與剪力硬化包絡上不會

Plastic point history 會顯示到目前階段為止，任何一步曾經塑性的點，適合看分階開挖中塑性區怎麼擴展。

初始應力後先看塑性點K0 procedure 之後如果有很多紅色塑性點，代表 K0 偏離 1 太多，應力已超出降伏面，要調整 K0 或接 nil-phase。只有少量塑性點時，接一個 plastic nil-phase 即可。
