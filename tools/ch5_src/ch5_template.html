Chapter 5

Material Model – Mohr-Coulomb

Mohr-Coulomb 是線彈性–完全塑性模型：降伏前是 Hooke 定律，碰到六角錐形的破壞面後應力停住、應變一直長。這一章從降伏面、流動法則、PLAXIS 的回傳計算一路講到材料視窗怎麼填，並用互動元素試驗看 ψ、排水條件與張力截斷的作用。

這一章要回答

E、ν、c、φ、ψ、σt 這六個數字，在 PLAXIS 裡各自決定了什麼？為什麼 MC 適合算破壞、不適合算變形與液化？

5.1

線彈性–完全塑性

MC 由三件事組成：

  • 彈性段：等向線彈性（Hooke 定律），只有 E、ν 兩個參數，E 不隨應力改變。
  • 破壞準則：Mohr-Coulomb，在主應力空間是一個沿靜水壓軸開放的六角錐。
  • 完全塑性：降伏面固定，只由 c、φ 決定，不隨塑性應變移動；沒有硬化，也沒有軟化。

應變分成彈性與塑性兩部分，只有彈性應變產生應力：

\[ \varepsilon = \varepsilon^{e} + \varepsilon^{p}, \qquad \dot\sigma' = D^{e}\left(\dot\varepsilon - \dot\varepsilon^{p}\right),\qquad \dot\varepsilon^{p} = \lambda\,\frac{\partial g}{\partial\sigma'} \]

塑性組成律的四個要素

要素回答的問題MC 的答案
彈性降伏前怎麼變形Hooke 定律，E、ν 為常數
降伏面 f = 0彈性與塑性的分界六個平面圍成的六角錐（5.3）
流動法則塑性應變往哪個方向非關聯：塑性勢 g 用膨脹角 ψ（5.4）
硬化法則降伏面會不會隨塑性應變改變不會，完全塑性

彈性參數之間的換算

\[ G=\frac{E}{2(1+\nu)},\qquad K=\frac{E}{3(1-2\nu)},\qquad E_{oed}=\frac{(1-\nu)E}{(1-2\nu)(1+\nu)},\qquad K_0^{\text{(一維壓縮)}}=\frac{\nu}{1-\nu} \]

以本專案岩體（E = 15 GPa、ν = 0.24）為例：G = 6.05 GPa、K = 9.62 GPa、Eoed = 18.0 GPa；一維壓縮的 K0 = 0.316。

一句話記住 MC

MC 只問「這個點破壞了沒有」。面內完全彈性、面固定不動，所以它擅長算極限荷重與穩定性，不擅長算破壞前的變形、應力路徑相依或循環累積（5.8）。

PLAXIS 的 MC 共 6 個力學參數：E、ν、c、φ、ψ、σt。

5.2

應力的描述與符號

一點的應力張量對稱，有 6 個獨立分量。轉到沒有剪應力的方向得到三個主應力。等向材料的組成律只需要主應力的大小，所以常把它們整理成幾個不變量：

偏應力 q\(\sqrt{\tfrac12\left[(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2\right]}\)；三軸時 \(=\sigma_1-\sigma_3\)管形狀（剪切）

符號慣例

土壤力學教科書與本章的原理、互動視窗都採壓為正。PLAXIS 的輸入與輸出採拉為正、壓為負：Output 中的有效應力多半是負值，σ′1 是「最大壓應力」，也就是數值最小（最負）的那一個。讀 PLAXIS 的式子與結果時要先換號。

5.3

降伏面與張力截斷

Mohr 圓與庫倫摩擦

Mohr 圓與破壞線 \(\tau = c + \sigma_n\tan\varphi\) 相切時發生破壞。用主應力寫成（壓為正）：

\[ f = \frac{\sigma_1'-\sigma_3'}{2} - \frac{\sigma_1'+\sigma_3'}{2}\sin\varphi - c\cos\varphi \le 0 \quad\Longleftrightarrow\quad \sigma_{1f}' = N_\varphi\,\sigma_3' + 2c\sqrt{N_\varphi},\qquad N_\varphi=\frac{1+\sin\varphi}{1-\sin\varphi} \]
導出量式子本專案岩體（c 1351 kPa、φ 38.8°）
單軸抗壓強度\(\sigma_{cm} = \dfrac{2c\cos\varphi}{1-\sin\varphi}=2c\sqrt{N_\varphi}\)5.64 MPa
MC 隱含的單軸抗拉強度\(\dfrac{2c\cos\varphi}{1+\sin\varphi}\)1.29 MPa
錐頂（等向受拉）\(\sigma_1'=\sigma_2'=\sigma_3' = -c\cot\varphi\)−1.68 MPa

σ2 不出現在式子裡，MC 只看最大與最小主應力；σ2 的影響要在 π 平面上才看得到。

PLAXIS 中的六個降伏函數

一般應力狀態下主應力的大小順序不固定，所以把準則套到每一對主應力（含順序對調），得到六個降伏函數。PLAXIS 採拉為正：

\[ \begin{aligned} f_{1a} &= \tfrac12(\sigma_2'-\sigma_3') + \tfrac12(\sigma_2'+\sigma_3')\sin\varphi - c\cos\varphi \le 0 & f_{1b} &= \tfrac12(\sigma_3'-\sigma_2') + \tfrac12(\sigma_3'+\sigma_2')\sin\varphi - c\cos\varphi \le 0 \\ f_{2a} &= \tfrac12(\sigma_3'-\sigma_1') + \tfrac12(\sigma_3'+\sigma_1')\sin\varphi - c\cos\varphi \le 0 & f_{2b} &= \tfrac12(\sigma_1'-\sigma_3') + \tfrac12(\sigma_1'+\sigma_3')\sin\varphi - c\cos\varphi \le 0 \\ f_{3a} &= \tfrac12(\sigma_1'-\sigma_2') + \tfrac12(\sigma_1'+\sigma_2')\sin\varphi - c\cos\varphi \le 0 & f_{3b} &= \tfrac12(\sigma_2'-\sigma_1') + \tfrac12(\sigma_2'+\sigma_1')\sin\varphi - c\cos\varphi \le 0 \end{aligned} \]

六個 \(f_i = 0\) 一起在主應力空間圍成固定的六角錐，錐軸是靜水壓軸。

Tension cut-off

c > 0 時 MC 容許拉應力，而且容許值隨 c 增加（上表 1.29 MPa），這對土壤與節理岩體往往不實際。PLAXIS 另外加三個降伏函數（拉為正）：

\[ f_4=\sigma_1'-\sigma_t\le0,\qquad f_5=\sigma_2'-\sigma_t\le0,\qquad f_6=\sigma_3'-\sigma_t\le0 \]

也就是不容許任何一個主應力的拉應力超過 σt。這三個函數採關聯流動。MC 材料預設勾選 tension cut-off、σt = 0。本專案 e7 取 σt = 289 kPa，只有 MC 隱含值的 22 %。

π 平面與 p–q 平面

三軸壓縮與三軸伸張破壞時 σ1/σ3 都等於 Nφ，但 σ2 的位置不同，所以在 p–q 平面是兩條斜率不同的線：

\[ q_c = M_c\,(p' + c\cot\varphi),\quad M_c=\frac{6\sin\varphi}{3-\sin\varphi};\qquad |q_e| = M_e\,(p' + c\cot\varphi),\quad M_e=\frac{6\sin\varphi}{3+\sin\varphi} \]

π 平面上伸張與壓縮的半徑比 \(r_e/r_c=(3-\sin\varphi)/(3+\sin\varphi)\)。φ = 30° 時 Mc = 1.2、Me = 0.857、re/rc = 0.714；若用 Drucker-Prager 圓通過壓縮角，伸張強度會高估約 1.4 倍。

錐面沿 p 軸方向開放：單純等向加壓永遠不會降伏。

5.4

流動法則與膨脹角

塑性應變率等於塑性乘數乘上塑性勢的梯度，\(\dot\varepsilon^{p} = \lambda\,\partial g/\partial\sigma'\)：

狀態條件λ
彈性\(f<0\)，或 \(f=0\) 但 \(\left(\partial f/\partial\sigma'\right)^{T}D^{e}\dot\varepsilon\le0\)（往面內卸載）λ = 0
塑性\(f=0\) 且 \(\left(\partial f/\partial\sigma'\right)^{T}D^{e}\dot\varepsilon>0\)（繼續往外推）λ > 0

持續降伏時應力點必須留在降伏面上（一致性條件 \(\dot f = 0\)），λ 就由這個條件求出。MC 的面不會動，所以應力停住、應變持續增加。

關聯與非關聯

若 g = f（關聯流動），塑性應變垂直於降伏面。對 MC 而言這會高估膨脹：剪動時體積一直以固定比例膨脹，在受圍束的問題（樁、錨碇、深開挖底部）中會提高圍壓、高估承載力。所以 PLAXIS 的 MC 另外定義塑性勢，把 φ 換成膨脹角 ψ，並去掉 c 項：

\[ g = \frac{\sigma_1'-\sigma_3'}{2} - \frac{\sigma_1'+\sigma_3'}{2}\sin\psi \qquad(\text{壓為正；另外五個同理}) \]

ψ 決定剪脹比

對 g 微分，平面應變（ε1 − ε3 方向剪動）時：

\[ \frac{\dot\varepsilon_v^{p}}{\dot\gamma^{p}} = -\sin\psi,\qquad \dot\gamma^{p}=\dot\varepsilon_1^{p}-\dot\varepsilon_3^{p} \]

三軸壓縮剛好落在角點（σ2 = σ3，兩個面同時作用），換成軸向塑性應變：

\[ \frac{\dot\varepsilon_v^{p}}{\dot\varepsilon_a^{p}} = -\frac{2\sin\psi}{1-\sin\psi} \]
  • ψ = 0：塑性流動不改變體積。
  • ψ > 0：只要持續剪動就一直膨脹。MC 沒有 dilatancy cut-off（只有 HS、HSsmall 有），不會在臨界狀態停下來。
  • ψ ≠ φ 時彈塑性勁度矩陣不對稱（5.5）。

角點的處理

光滑降伏面的塑性理論在角點不適用：應力落在兩個面的交線上時，法線是一個扇形，不是唯一方向。三軸壓縮與三軸伸張剛好都在角點上。

做法內容
多勢函數（Koiter 法則）\(\dot\varepsilon^{p}=\lambda_1\,\partial g_1/\partial\sigma' + \lambda_2\,\partial g_2/\partial\sigma' + \dots\)，各個 λ 由對應的降伏函數決定。PLAXIS 用這種精確的尖角做法，5.6 的互動視窗也是
角點修圓用平滑曲線取代尖角（例如在 Lode 角接近 30° 處圓化），回傳較穩定，但和原本的 MC 略有差異；OpenSees 的部分 MC 實作就是這樣
5.5

PLAXIS 在應力點上怎麼算 MC

有限元素的整體迭代（第 1 章）每一次都會給每個應力點一個應變增量 Δε。組成律的工作只有一件：由 Δε 算出新的應力 σ。MC 用「彈性試算＋回傳」：

  1. 彈性試算：\(\sigma^{tr} = \sigma^{i-1} + D^{e}\Delta\varepsilon\)。
  2. 若九個函數（六個 MC＋三個張力）都 \(f(\sigma^{tr}) \le 0\)：彈性，\(\sigma = \sigma^{tr}\)，結束。
  3. 否則求塑性乘數 \(\Delta\lambda = \langle f(\sigma^{tr})\rangle / d\)，\(d = (\partial f/\partial\sigma)^{T} D^{e}\, (\partial g/\partial\sigma)\)（完全塑性，硬化模數為 0）。
  4. 拉回：\(\sigma = \sigma^{tr} - \Delta\lambda\, D^{e}\,\partial g/\partial\sigma\)。
  5. 角點：兩個（或三個）面同時作用，聯立求各自的 Δλ；張力：受拉主應力直接拉回 σt。

MC 的每個面在主應力空間都是平面、塑性勢的梯度是常數，所以上面的回傳是一步到位的精確解，不必迭代。互動視窗（5.6）用的就是同一套演算法：九個函數任取 1–3 個為作用面，解出 Δλ ≥ 0 且回傳後所有 f ≤ 0 的那一組。

彈塑性勁度矩陣

\[ \dot\sigma' = \left(D^{e} - \frac{\alpha}{d}\,D^{e}\frac{\partial g}{\partial\sigma'}\frac{\partial f}{\partial\sigma'}^{T}D^{e}\right)\dot\varepsilon,\qquad \alpha = \begin{cases}0 & \text{彈性}\\ 1 & \text{塑性}\end{cases} \]
  • g ≠ f 時 \(\partial g/\partial\sigma'\) 與 \(\partial f/\partial\sigma'\) 不同，括號內的 \(D^{ep}\) 不對稱，整體勁度要改用非對稱解法，成本約加倍。
  • PLAXIS 的 MC 不用 \(D^{ep}\) 組勁度，而是一直用彈性勁度 \(D^{e}\) 迭代，所以不受非對稱影響，代價是迭代次數較多；不平衡力靠迭代重新分配。

局部誤差與 inaccurate 點

迭代中某個應力點的「平衡應力」\(\sigma^{eq}\) 和回傳得到的 \(\sigma^{c}\) 差太多，就記為 inaccurate：

\[ \text{local error} = \frac{\lVert\sigma^{eq}-\sigma^{c}\rVert}{\max(\tau_{max},\ c,\ 1\ \text{kPa})},\qquad \text{收斂要求：inaccurate 點數} < 0.1\times\text{塑性點數} + 3 \]
Active tasks 視窗欄位和 MC 的關係
Plastic stress points回傳到 MC 面上的應力點數
Tension points回傳到 tension cut-off 的點數；這種點受拉方向勁度為零
Apex points回到錐頂的點，容許剪應力為 0
Inaccurate／Tolerated局部誤差超過容許的點數／容許數
本專案實例

plan_e 的 e1 在 L16 停在 ΣMstage 0.551、CSP ≈ 0：166 個塑性點中 116 個是張力點。開挖面幾個元素全進入張力截斷、勁度為零，位移發散到步數用完（Error 102）。這不是整體崩塌，而是 tension cut-off 造成的局部零勁度；e4 之後加密洞周網格、修正拱腳近點才算完。

MC 適合做什麼

MC 只需要 E、ν、c、φ、ψ 五個參數，都能從常規試驗取得。用 c′、φ′ 描述破壞時的有效應力狀態相當合理，所以適合做破壞荷重與穩定性這類問題，或當作第一近似；拿它預測變形就要很小心選 E。對液化而言最關鍵的是第一、三列：面內沒有塑性體積變化、也沒有載重歷史，孔隙水壓無法累積——這正是第 6 章 PM4Sand 要補的。

E 要選哪一個

  • E0：初始切線模數，線彈性範圍大的材料用它。
  • E50：50 % 強度處的割線模數，一般加載問題用它。
  • Eur：卸載–再加載模數，通常明顯大於 E50。開挖、隧道屬於卸載問題，應該用 Eur 或岩體變形模數。

土壤勁度會隨圍壓增加、隨應力路徑改變，但 MC 的 E 是常數，所以要選一個與應力水準、應力路徑一致的值。Undrained (A)(B) 時輸入的是有效 E′，PLAXIS 會自動處理不可壓縮性（5.10）。

ν 與 K0

  • 一維壓縮下 MC 給出 \(K_0=\nu/(1-\nu)\)，所以常用 K0 反算 ν，多半落在 0.3–0.4；這種方式得不到 K0 > 1。
  • 卸載問題（開挖）取 0.15–0.25 較適當。
  • Undrained (A)(B) 時 ν′ 要小於 0.35，確保土骨架比孔隙水容易壓縮。

G、Eoed、波速與隨深度增加

輸入 G 或 Eoed 中的任一個，程式會換算出 E，ν 保持不變。動力分析時勁度要能正確預測波速，通常要用小應變勁度；MC 在破壞面內只有彈性應變，沒有遲滯阻尼、應變累積或液化，要另外設 Rayleigh 阻尼。

\[ E(y) = E_{ref} + (y_{ref}-y)\,E_{inc},\qquad c(y) = c_{ref} + (y_{ref}-y)\,c_{inc}\qquad (y<y_{ref}) \]

這兩個值只隨深度變化，計算中不會隨應力狀態改變。

強度參數

  • c′ 配 φ′：Drained 或 Undrained (A)，做有效應力分析，壓密後強度會自動增加。
  • su 配 φ = 0：Undrained (B)(C)，MC 退化為 Tresca，可直接控制剪力強度；Undrained (A) 用 c′、φ′ 時，模型給出的不排水強度可能和實際不同，建議每個階段檢查 \(|\sigma_1-\sigma_3|\le 2s_u\)。
  • c = 0 可以算，但某些選項表現不好，近地表層建議至少給 0.2 kPa。
  • φ 高時塑性計算量明顯增加，初步計算應避免太高的 φ。
  • ψ：黏土除重度過壓密者外 ≈ 0；石英砂 ≈ φ − 30°；負值只適用極鬆砂。Undrained (B)(C) 時 ψ 自動設為 0。Undrained (A) 配 ψ > 0 時，剪脹會產生拉的孔隙應力，強度無限增加，必須開 cavitation cut-off（5.6 可以實際看到）。
  • σt：預設勾選 Tension cut-off、σt = 0；岩體可依 Hoek-Brown 換算 \(\sigma_t = s\,\sigma_{ci}/m_b\) 給非零值。

Hoek-Brown 換算為等值 MC

岩石的勁度可視為常數，這點 MC 適用；但強度隨圍壓呈非線性，大範圍應力下 MC 的直線包絡不夠。可以在指定的圍壓範圍 \(-\sigma_t < \sigma_3' < \sigma_{3,max}'\) 內做平衡擬合：

\[ \sin\varphi' = \frac{6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}}{2(1+a)(2+a)+6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}} \] \[ c' = \frac{\sigma_{ci}\left[(1+2a)s+(1-a)m_b\sigma_{3n}'\right](s+m_b\sigma_{3n}')^{a-1}}{(1+a)(2+a)\sqrt{1+\dfrac{6a\,m_b\,(s+m_b\sigma_{3n}')^{a-1}}{(1+a)(2+a)}}},\qquad \sigma_{3n}'=\frac{\sigma_{3,max}'}{\sigma_{ci}} \]

σ′3,max 依應用而定（例如洞周的最大圍壓），擬合範圍不同得到的 c′、φ′ 也不同。用等值 MC 做 Safety 得到的安全係數，和直接用 Hoek-Brown 做 Safety 的結果不會相同。

5.13

輸出：塑性點與強度折減

塑性點怎麼看

Output 的 Stresses → Plastic points 顯示處於塑性狀態的應力點，畫在未變形的網格上：

符號意義MC 會出現嗎
紅色方塊（Failure point）應力落在 MC 破壞包絡上會
白色方塊（Tension cut-off point）觸發 tension cut-off會（開啟 cut-off 時）
藍色倒金字塔（Cap point）正常壓密，應力等於預壓密應力不會
綠色金字塔（Hardening point）剪力硬化包絡上不會
棕色菱形（Cap + Hardening）同時在帽蓋與剪力硬化包絡上不會

Plastic point history 顯示到目前階段為止任何一步曾經塑性的點，適合看分階開挖中塑性區怎麼擴展。直接讀 data.db 時，塑性點是積分點上的整數旗標（第 3、4 章）。

初始應力後先看塑性點

K0 procedure 之後如果有很多紅色塑性點，代表 K0 偏離 1 太多，初始應力已超出降伏面，要調整 K0 或接 nil-phase；只有少量時，接一個 plastic nil-phase 即可。本專案 Ph0 算完要先確認 σv ＝ γ·深度、σh ＝ K0·σv，而且沒有塑性點。

強度折減（Safety）

做法

逐步折減 tanφ、c 與張力強度，直到結構破壞：\(\Sigma M_{sf} = \tan\varphi_{input}/\tan\varphi_{reduced} = c_{input}/c_{reduced}\)。ψ 原則上不折減；φ 降到等於 ψ 之後，ψ 隨 φ 一起降。介面強度同樣折減，Plate、Anchor 可用 Enhanced safety 一併折減。

判讀

破壞機制完全發展時 FS = ΣMsf。用 Curves 確認 ΣMsf 已趨於定值；沒穩定就加大步數（預設 100 步）。需用 Arc-length control、容許誤差 ≤ 1 %（預設值即符合），網格要夠細。結果和極限平衡法的滑弧分析相近。
