3.1

專案資料夾裡的檔案

存檔後，一個 PLAXIS 專案是 xxx.p2dx 加上同名的 xxx.p2dxdat 資料夾。.p2dx 只是入口，所有東西都在資料夾裡，而且大多是文字檔或 SQLite，可以直接讀。

檔案寫入時機內容
xxx.p2dx、data.p2dx存檔純文字的指令紀錄（含 GUI 操作留下的 _set …），可以整理回第 2 章的 Command txt
data.plxml存檔Input 的模型狀態（二進位 XML）：幾何、材料、相位設定
data.opi存檔INI 文字：各相名稱、前一相、計算狀態、起訖步號
data.db存檔SQLite：網格、物件、相位設定與全部計算結果（這一章的主角）
data.meshinput／meshoutput／meshinfo產生網格網格的輸入、節點與元素、網格紀錄（失敗原因寫在 meshinfo）
data.eNN、mNN、mxNN每相開始交給計算核心的模型與材料輸入
log.dNN每相結束結果碼 ErrorCode、錯誤訊息、步數
data.convd.rrNN每相結束收斂紀錄：每步每次迭代的 Global error、塑性／張力點數、最大不平衡力位置
debug.dNN每相結束計算核心紀錄：材料參數、每步 ΣMstage、CSP、計時
data.cxx.rrNN每相結束Curve points（第 2 章選的量測點）逐步資料

data.db 什麼時候才有結果

  1. 建模存檔：data.db 幾乎是空的，只有網格、物件與相位設定（plan_e 約 24 MB）。
  2. 計算中：每相的結果先寫進暫存資料庫（{GUID}.db）。
  3. 計算後存檔：暫存結果才寫回 data.db，檔案增為 1–3 GB。
讀取前先確認兩件事

① 計算完要存檔，否則結果不在 data.db。② PLAXIS 開著這個專案時，先把 data.db 複製一份再讀；讀取一律用唯讀模式（第 4 章）。

用文字紀錄找問題

相位失敗時，先看 log.dNN 的 ErrorCode，再看 data.convd.rrNN 後段每步的張力點數與最大不平衡力節點，最後到 data.db 讀那一相最後幾步的位移場，就能定位發散的位置。錯誤碼的意義見第 1 章。

3.3

表怎麼串在一起

資料庫的核心是 Result。它的每一列只存「編號＋一包數字」，編號的意思都要去其他表查。讀懂這張圖，就讀懂了大半個資料庫。

以「L05 結束時，某個岩體區塊的位移」為例，要依序找出四個編號：

  1. 哪一步：在 I_Phase 找到 L05 的 ID，再到 K_Steps 找它的最後一步。完整結果只存在每個階段的最後一步。
  2. 哪一塊網格：在 MeshEntity 找到那個岩體區塊（也可以從 StagedUserFeature 的名稱找）。
  3. 哪一種量：在 Variables 找 Displacement。
  4. 排在哪裡：位移排在節點上，所以 DataLayout 選 Unique Nodal。

四個編號都有了，就能從 Result 取出 Data，再依 DataInterpretation 把二進位轉成數字。

3.4

先記住四件事

  • BLOB 不是亂碼查詢工具顯示的 x'cdcc…' 是二進位數字的十六進位寫法。每 8 bytes 是一個 Double，位元組倒過來存（little-endian）。用 Python 的 numpy 一行就能還原。
  • 節點編號從 1 開始連接表與節點群裡的節點編號是 1～406,281，Python 陣列從 0 開始，所以節點 n 的座標在 xy[n - 1]。
  • 只有最後一步有完整結果這個模型設定每個階段只保存 1 步。中間的計算步只存曲線點附近的小區塊（auxiliary entity），畫雲圖要用每個階段的最後一步；GlobalResult 則每一步都有。
  • ID 各專案不同同樣是三角形元素，MeshComponentTypeID 在不同專案可能不同；寫程式時用名稱（Description、Name）查，不要寫死數字。
和 PLAXIS Output 的關係

PLAXIS Output 畫的雲圖、曲線，資料都來自這個檔案。直接讀 data.db 的好處是可以一次批次取出所有階段、所有區塊的數字，不用在 Output 裡一頁一頁點，也不用再用 getresults 匯出 CSV。

3.5

不寫程式，快速看一眼

只是想看有哪些表、有幾筆資料，有兩種免寫程式的方法：

DB Browser for SQLite

免費的圖形介面工具。用 Open Database Read Only 開啟 data.db，Browse Data 頁可以逐表瀏覽、Execute SQL 頁可以直接下查詢。

sqlite3 命令列

到 sqlite.org 下載 sqlite-tools（Windows 版），解壓後在 PowerShell 執行，加 -readonly 避免改到檔案。

PowerShell
cd "E:\01地下電廠洞室開挖支撐設計分析\KuanMing_Plaxis2D\KuanMing_plan_e\e5_TC289_NearMesh\e5_TC289_NearMesh.p2dxdat"
sqlite3.exe -readonly data.db
sqlite3 裡面輸入
.tables
.headers on
.mode box
SELECT Number, Name FROM I_Phase WHERE PhaseTypeID = 1 ORDER BY Number;
.quit

遇到 BLOB 欄位（Data、NodeData、ComponentData）就要改用 Python，請看 第 4 章 Post-Processing。
